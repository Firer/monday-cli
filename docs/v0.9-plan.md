## 2. Empirical probe basis (M50 — already done)

The 2026-05-22 dev-board sweep IS M50's pre-flight wire probe. Pinned:
- `create_subitem(parent_item_id)` nests to depth-3+ on `multi_level`
  boards at API `2026-01` (the CLI pin) — `parent_item` chains, all on
  the host board, the board carries a `subtasks`-type column
  self-referencing `boardId: <self>`.
- `Board.hierarchy_type` ∈ {`classic`, `multi_level`}; readable at
  `2026-01` via raw GraphQL (SDK-drift field, like `is_leaf`).
- Classic boards genuinely lack the nesting home at `2026-01` — so M50
  must KEEP a (corrected) classic-board path: reject classic-board
  `--parent` nesting with an accurate message, allow it on multi-level.

Probe scripts: `scripts/probe/m40-multilevel-*` + `kanban-columns.ts`
(local/gitignored). Full map: user-memory
`project_multilevel_dev_board_capabilities`.
